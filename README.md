# 🍲 App de Receitas

Aplicativo de receitas desenvolvido com **React Native**, permitindo que usuários possam **postar receitas**, **visualizar receitas de outros usuários**, **deixar feedbacks**, entre outras funcionalidades relacionadas à culinária.

## 📱 Funcionalidades

- ✅ Postar receitas com título, imagem, ingredientes e modo de preparo
- ✅ Visualizar receitas de outros usuários
- ✅ Comentar e dar feedbacks nas receitas
- ✅ Marcar receitas como favoritas
- ✅ Pesquisar receitas por nome ou ingrediente

## 🛠 Tecnologias Utilizadas

- [React Native](https://reactnative.dev/) — estrutura principal do app
- [Expo](https://expo.dev/) — ambiente para desenvolvimento e testes
- [React Navigation](https://reactnavigation.org/) — navegação entre telas
- [AsyncStorage](https://react-native-async-storage.github.io/async-storage/) — armazenamento local de dados
